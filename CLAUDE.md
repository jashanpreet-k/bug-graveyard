# Build log: NOTES.md

This project is a DEV Sanity Challenge entry. `NOTES.md` is the build log the write-up
will be based on.

At the end of every phase, append a new entry to the bottom of `NOTES.md` without
waiting to be asked. A phase ends when the user says it is done or when a day of the
5-day plan is finished. If you're unsure whether a phase has ended, ask before writing.

Use this format:

```markdown
## Phase N: <name> (YYYY-MM-DD)

### What I asked for
The user's prompts from this phase, summarized.

### What was built
Files created or changed, one line each.

### What went wrong and how we fixed it
Each problem and its fix. If nothing went wrong, say so.

### Sanity notes for the write-up
Anything surprising or interesting about Sanity that is worth mentioning.
```

Write the entry in first person, as the user's own notes ("I asked for…"). Include
real error messages, commands and versions rather than paraphrases.
