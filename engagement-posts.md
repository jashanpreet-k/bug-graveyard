## 2. Sanity Discord #showcase

Built Bug Graveyard for the DEV Sanity Challenge (Path 2) 🪦

Fixed bugs get buried. When one comes back, it rises as a zombie linked to its old grave. A Zombie Detector compares new reports to old graves using clear signals (same cause, language, component, shared keywords) and only asks an Agent Action to write the reason.

Uses custom document actions, a Tombstone view inside the Studio, a scheduled Function (the Gravedigger), and an App SDK app called The Morgue.

One thing that tripped me up: my scripts kept missing drafts because queries defaulted to the published perspective. Switching to raw fixed it.

## 3. LinkedIn

I built a graveyard for software bugs. 🪦

For the DEV x Sanity Challenge, I made Bug Graveyard: every fixed bug gets a tombstone with its cause of death and an epitaph. When a bug comes back (a regression), it rises from its grave as a zombie, linked to its old life.

The part I'm proudest of is the Zombie Detector. When someone reports a new bug, it checks the old graves and shows exactly why it might be the same bug returning: same cause, same language, same component, shared keywords. No mystery AI score.

I built it with Next.js and Sanity, working with Claude Code. I learned that Sanity is much more than a CMS: custom Studio actions, scheduled functions and a dashboard app all came together here.
